Performance and limits
----------------------
At 1x internal resolution and the 60 fps setting, the debug overlay showed
roughly 18–20 fps at the title and 1–1.2 fps in Delfino Plaza. Plaza rendering
cost roughly 750–900 ms per frame, with game logic roughly 35–45 ms. Expensive
GLES ordered numeric pixel-metric draws are a principal renderer bottleneck.
Removing per-triangle synchronous uniform queries and GPU index readbacks
resolved multi-minute frame stalls, but does not make this emulator playable
at full speed. These measurements are not an AYN Thor benchmark.

In the release build's plaza arrival, another overlay sample showed 1.5 fps,
635.9 ms rendering, 33.5 ms game logic, and 674.6 ms average total frame time.
Release movie playback showed a stable 30 fps. Neither the debug nor release
plaza measurements establish performance on native ARM64 handheld hardware.

Physical handheld performance, thermals, controller feel, rumble, audible
output, and actual 16 KiB-page runtime remain untested. The emulator was
started with host audio disabled; the Android audio queue initialized, but
audibility is not claimed. Keyboard input validates control functionality,
not a physical gamepad. This launcher currently covers the base game; Eclipse
and HD texture-pack installation remain desktop-launcher features.

2026-10-12 Adreno 750 black-screen fix (v7)
-------------------------------------------
A tester reported immediate black video with audio on an S24 Ultra running
Android 16. The supplied game log identifies Qualcomm Adreno 750 GLES 3.2
V@0762.41 and successful context creation, followed by repeated shader
compile/link errors: gl_ClipDistance is a reserved built-in name. The error
is at the adapter's explicit standalone out float gl_ClipDistance[2] line.

The GLES adapter now relies on EXT_clip_cull_distance's predeclared array
and sizes it implicitly with constant indices 0 and 1, as the extension
specification allows. The extension, writes and both hardware clip planes
remain enabled. Shader failure logs now show the adapted GLES source sent
to the compiler. The shader cache already hashes adapted source, so changed
programs automatically invalidate previous binary cache entries.
Specification: https://registry.khronos.org/OpenGL/extensions/EXT/EXT_clip_cull_distance.txt

Three pixel checks exercise near/far rejection and retained inside geometry
on contexts supporting clip distances. Android ReDroid with shader cache off:
66 passed, 0 failed, with 13 shaders compiled and no GL errors. Desktop GX:
66 passed, 0 failed. Launcher Node: 228 passed, 0 failed. Debug and optimized
release APKs compiled; v7 retains ARM64-only libraries, 16 KiB ELF/APK
alignment and a verified development signature. Release startup at 30 fps,
1x scale and 4:3 rendered the native title with shader caching disabled;
no shader compile/link errors were observed in the captured startup log.
Prerecorded movies were skipped in that local startup check.

The updated APK was installed over the previous build with ROM/save data

This does not claim Android 16 or Adreno hardware validation from the Android
